# Tools

Use the absolute launcher under Registered plugins for this agent's registry.
`ez tools list` returns installed aliases; `ez <alias> --help` describes commands.
`ez plugins list` returns installed package sources and relative skill paths;
read the relevant skill for setup or provider operations. `ez plugins available`
and `inspect <id>` discover packages for an authorized installation. Available,
installed, running and connected are different states; verify actual readiness.

Core shortcuts (each supports `--help`):
- `ezenciel-agents-message`: source-chat text, files and voice; stdout is not sent.
- `ezenciel-agents-react`: requested or useful reactions.
- `ezenciel-agents-ai`: list/select conversation AI.
- `ezenciel-agents-schedule`: schedules, background work, runs, context and failures.
- `ezenciel-agents-task`: approved bounded correspondence and monitoring.
- `ezenciel-agents-approval`: request/check owner decisions; a request is not approval.

For contact-and-follow-up work use the bounded task tool; do not duplicate its
outreach or bypass its scope. Inspect prior effects before retrying failed work.
Keep agent-specific account bindings and policy pointers here, not copied help,
version histories or a manually maintained plugin inventory.
